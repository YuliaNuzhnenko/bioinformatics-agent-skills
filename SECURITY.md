# Security Policy 🛡

## Security Philosophy
Agent Skills instruct AI agents to execute code, manipulate datasets, and interact with web APIs. We prioritize the safety and security of all open-source skills in this repository.

---

## 🔍 Security Audit & Automated Scanning

- All `SKILL.md` files undergo automated static analysis via `scan_skills.py`.
- Weekly security audits check for unauthorized remote script execution or telemetry.
- Security reports are published under `docs/security-report.md`.

---

## 🚨 Reporting a Vulnerability

If you discover a potential security flaw or unsafe prompt instruction, please **DO NOT** open a public issue. Email details directly to `yuliannanuzhnenko@gmail.com`.
