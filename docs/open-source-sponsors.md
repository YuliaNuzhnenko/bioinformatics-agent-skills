# Open-Source Credits & Project Support ❤️

`bioinformatics-agent-skills` is built upon the foundation of outstanding open-source scientific tools:

- **Scanpy** & **AnnData** — Single-cell genomics analysis framework
- **Biopython** — Structural PDB parsing & sequence utilities
- **RDKit** — Open-source cheminformatics engine
- **PyDESeq2** / **DESeq2** — Differential expression analysis
- **Nextflow** — Workflow orchestration engine
- **QIIME2** — Microbiome & 16S bioinformatics platform
- **GATK4** — Genome Analysis Toolkit

Please consider starring and sponsoring these foundational projects!
